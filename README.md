# swiggy-sales-analysis-excel-dashboard

## 📊 Swiggy Sales Analysis Dashboard

### Project Overview

An interactive Excel dashboard designed to analyze Swiggy's sales performance, customer ratings, order trends, and geographical sales distribution.

- **Total Sales:** ₹53.01M

### Dashboard Features

- Monthly Sales Analysis
- Veg vs Non-Veg Sales Analysis
- Daily Sales Trends
- Weekly Sales Trends
- Quarterly Performance Analysis
- City-wise Sales Analysis
- State-wise Sales Distribution
- Interactive Filters (Month, Dish Name, City)

### Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Data Visualization

### Project Objective

To transform raw sales data into meaningful business insights through an interactive Excel dashboard, helping businesses monitor performance and make data-driven decisions.
